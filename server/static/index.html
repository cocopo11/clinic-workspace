예시 온보딩 / 2026.11.14 / §2

진료 문의 전달 기준 · v0.1
예시 CS 기준 / 2026.11.14 / §3

개별 치료 효과, 진단, 약물 조정에 관한 문의는 의료진에게 전달합니다. 직원이 치료 효과를 보장하지 않습니다.
